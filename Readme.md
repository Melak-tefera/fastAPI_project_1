# FastAPI Users API

A simple user management REST API built with FastAPI, SQLAlchemy, Pydantic, and SQLite.

This project demonstrates a basic API workflow: receiving request data, saving users to a database, and returning structured responses.

## Features

- Create a user
- Retrieve all users
- Retrieve a user by ID
- Handle missing users with a `404 Not Found` response
- Validate request and response data using Pydantic
- Test endpoints through interactive API documentation

## Tech Stack

- **Framework:** FastAPI
- **Database:** SQLite
- **ORM:** SQLAlchemy
- **Validation:** Pydantic
- **Server:** Uvicorn
- **Environment configuration:** python-dotenv

## Getting Started

### 1. Get the source code

Clone this repository using its GitHub URL, then open a terminal in the project directory.

### 2. Create a virtual environment

```bash
python -m venv .venv
```

### 3. Activate the virtual environment

Windows — Git Bash:

```bash
source .venv/Scripts/activate
```

Windows — PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Windows — Command Prompt:

```cmd
.venv\Scripts\activate.bat
```

macOS / Linux:

```bash
source .venv/bin/activate
```

### 4. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 5. Configure the database

Create a `.env` file in the project root:

```dotenv
DATABASE_URL=sqlite:///./app.db
```

### 6. Start the development server

```bash
python -m uvicorn main:app --reload
```

The server runs at:

```text
http://127.0.0.1:8000
```

## Interactive API Documentation

With the server running, open:

- **Swagger UI:** http://127.0.0.1:8000/docs
- **ReDoc:** http://127.0.0.1:8000/redoc

In Swagger UI, select an endpoint, click **Try it out**, and then click **Execute**.

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/users` | Create a user |
| `GET` | `/users` | Retrieve all users |
| `GET` | `/users/{id}` | Retrieve a user by ID |

### Create a User

**Request**

```http
POST /users
Content-Type: application/json
```

```json
{
  "name": "Meleak"
}
```

**Example response with the `UserRead` response model**

```json
{
  "id": 1,
  "name": "Meleak"
}
```

IDs are generated by the database.

### Retrieve All Users

**Request**

```http
GET /users
```

**Example response**

```json
[
  {
    "id": 1,
    "name": "Meleak"
  },
  {
    "id": 2,
    "name": "Abel"
  }
]
```

An empty database returns:

```json
[]
```

### Retrieve a User by ID

**Request**

```http
GET /users/1
```

**Example response**

```json
{
  "id": 1,
  "name": "Meleak"
}
```

**User not found — `404`**

```json
{
  "detail": "User not found"
}
```

## Data Models

### UserCreate

Request schema for creating a user.

| Field | Type | Required |
|-------|------|----------|
| `name` | string | Yes |

### UserRead

Response schema for reading a user.

| Field | Type |
|-------|------|
| `id` | integer |
| `name` | string |

## How It Works

1. FastAPI receives an HTTP request.
2. Pydantic validates the request body when creating a user.
3. A database session is provided through dependency injection.
4. SQLAlchemy creates or retrieves database records.
5. FastAPI returns data using the endpoint’s response schema.

The application initializes the database tables through:

```python
Base.metadata.create_all(bind=engine)
```

## Current Scope

This project implements user creation and retrieval.

Authentication, user updates, and user deletion are not currently implemented.
